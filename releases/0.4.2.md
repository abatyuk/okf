# OKF 0.4.2

This patch release fixes registered sibling references in change sets and preserves
cross-bundle link targets when moving concepts. The CLI and both agent plugins are
version 0.4.2; the OKF document specification remains v0.2.

## Cross-bundle changes and moves

- Change-set preview and apply resolve references to registered sibling bundles from
  the original bundle location, including declared metadata references and typed file
  sources. Valid sibling references no longer fail because validation uses a staged copy.
- Sibling targets are checked read-only. Missing targets, unregistered paths, and symlink
  escapes remain blocked; sibling registration does not authorize cross-bundle writes.
- Moving a concept preserves its relative references to sibling bundles. Sibling paths
  no longer alias local concept IDs during inbound link updates.

## Upgrade and compatibility

Install 0.4.2 using the standalone installer or download the archive for your architecture.
No document migration is required. Plugins continue to support stable CLI versions
`>=0.4.0, <0.5.0`. Command syntax is unchanged. macOS binaries retain Developer ID signing
and Apple notarization; Linux binaries retain native musl builds.

## Validation

Regression tests cover preview/apply without sibling writes, move target preservation,
missing and unregistered targets, symlink escapes, typed file sources, declared metadata
references, and rejection of cross-bundle writes. Release checks include workspace tests
with default and URL-source features, formatting, release metadata and distribution tests,
generated references, and skill workflows.
