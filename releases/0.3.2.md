# OKF 0.3.2

## CLI and plugin

This release distributes the current OKF CLI and agent skills for OKF v0.2 bundles.
The CLI supports bundle validation, structured authoring, retrieval, source tracking,
ontology operations, and multi-bundle catalogs. The plugin requires a stable CLI
version >=0.3.2 and <0.4.0; incompatible installations receive installation instructions.

## Prebuilt downloads

Ready-to-run archives are provided for Linux x86_64 and ARM64 (static musl builds),
and macOS Intel and Apple Silicon (deployment target macOS 13 or later).
Rust is not required. Each archive contains `okf`, the README, and the license.
`SHA256SUMS` contains archive checksums. Download manually or use the optional
standalone `install.sh VERSION` script to install/update `~/.local/bin/okf`.
Skills never run the installer. Git-based operations still require Git on PATH.

Official binaries enable `url-sources` for explicit remote artifact retrieval
(`artifact show --fetch`). The CLI fingerprint refresh path does not yet connect
the network client, so URL fingerprint refresh remains unavailable.

## Initial release caveats

macOS binaries are not Developer ID signed or notarized. Gatekeeper may prevent
execution depending on download method and local policy. Signing and notarization
are planned for a later release; do not disable Gatekeeper globally.

The release matrix tests binaries on the configured GitHub runners. The macOS 13
deployment target is not a claim that every older OS installation has been tested.
Linux static builds avoid a runtime glibc dependency but still require a compatible
kernel and CPU. No Windows binaries are provided.
