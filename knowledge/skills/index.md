# Skill

* [okf:infer-ontology skill](infer-ontology.md) - Infers advisory custom fields and references from support counts while excluding standard OKF families and preserving exact unknown types.
* [okf:ingest skill](ingest.md) - Researches a repository through complete source inventory and authors grounded OKF v0.2 concepts using standard provenance before drift extensions.
* [okf:init skill](init.md) - Creates a valid OKF v0.2 bundle and scaffolds portable concepts or exact Attested Computations, with ontology treated as an optional tool sidecar.
* [okf:migrate skill](migrate.md) - Faithfully migrates authored or legacy documents into OKF v0.2 with standard sources, claim footnotes, and preserved extensions.
* [okf:ontology skill](ontology.md) - Manages an optional advisory ontology while keeping portable OKF fields and exact Attested Computation semantics separate from custom rules.
* [okf:reorganize skill](reorganize.md) - Moves concepts while rebasing body links and standard source resources, preserving opaque artifacts and validating regenerated indexes.
* [okf:repair skill](repair.md) - Uses okf doctor to diagnose and safely repair an existing bundle for v0.2 while preserving legal extensions and stopping for semantic choices.
* [okf:retrieval skill](retrieval.md) - Answers from a bundle through progressive disclosure, source lineage, bounded artifact retrieval, and explicit lifecycle, verification, and runtime caveats.
* [okf:review-verify skill](review-verify.md) - Reviews concepts against declared evidence and appends document-level verified events with the real reviewer actor, never as a substitute for runtime attestation.
* [okf:update skill](update.md) - Separately triages lifecycle expiry, standard source evidence, fingerprint drift, and content changes, then reconciles concepts without overstating refresh.
